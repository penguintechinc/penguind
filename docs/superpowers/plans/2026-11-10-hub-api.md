# hub-api Implementation Plan

**Goal:** CLI-only management hub for penguind agents: Python 3.13 Quart service `services/hub-api` + `pdcli hub ...` admin commands.
**Contract:** `services/hub-api/openapi/v1.yaml` · **Protocol:** `docs/hub-protocol.md`
**Branch:** `feature/hub-api` off `release/v0.1.X`

## Context

- v1 scope: WASM module distribution + config/feature flags. Remote jobs out of scope
- No web UI; admin surface is pdcli only
- Hub is stateless; Postgres via penguin-dal; blobs in S3-compatible store with SSE
- Hub never holds signing keys; uploads carry minisign signature, hub recomputes sha256 and verifies against configured pubkeys before accepting
- Agent side reuses `ModuleManifest {id, version, sha256, signature, binary_url}` from `penguin-wasm-host` `distribution/fetcher.rs` + `verification.rs` (on `feature/wasm-tool-call-host`; not yet on `release/v0.1.X` — T4 depends on that merge)

## Resolved Decisions

| Topic | Decision |
|---|---|
| Group merge | allowed_tools ∩, numeric limits min, agent override wins per field |
| Flags | restrict-only: effective = license && hub |
| Admin auth | OIDC device flow, token in OS keychain; scopes `hub:<resource>:<read\|write>` + mandatory `tenant` |
| Agent auth | SPIFFE mTLS; fallback machine JWT from one-time bootstrap token, rotating refresh |
| Polling | 5 min ± jitter, ETag / If-None-Match, 304/410 |
| Blob | S3-compatible + SSE, presigned 302 for downloads |
| Signing | minisign over `penguin-wasm-module/v1\nid=..\nversion=..\nsha256=..\n`; offline signer |

## Data Model (penguin-dal, every table tenant-scoped)

All: `id BIGINT PK`, `public_id UUID UNIQUE`, `tenant_id BIGINT`, `created_at`, `updated_at`. Enums are int codes.

| Table | Key columns |
|---|---|
| `groups` | name, description, policy JSONB |
| `agents` | status (1 active/2 stale/3 revoked), platform (1 linux/2 macos/3 windows), agent_version, spiffe_id, override JSONB, last_seen_at, applied_etag, last_report JSONB |
| `group_members` | group_id FK, agent_id FK (unique pair) |
| `module_versions` | module_id, version, sha256, signature, size_bytes, blob_key, status (1 available/2 yanked); unique(tenant, module_id, version) |
| `group_modules` | group_id FK, module_version_id FK |
| `flags` | key, enabled, scope (1 tenant/2 group), group_id FK null |
| `bootstrap_tokens` | token_hash (argon2id), group_ids, expires_at, used_by_agent_id |
| `refresh_tokens` | agent_id FK, hash, chain_id, rotated_at, revoked_at |

No PII stored; agents identified by UUID only.

## Endpoints (summary — authoritative: OpenAPI)

| Prefix | Resource | Ops | Scope |
|---|---|---|---|
| `/api/v1/groups` | groups, members, modules | list/create/get/patch(If-Match)/delete, PUT members, GET/PUT modules | `hub:groups:*` |
| `/api/v1/agents` | agents, override | list (filters group/status/stale)/get/revoke, PUT/DELETE override | `hub:agents:*` |
| `/api/v1/modules` | module versions | list/upload(multipart)/get/patch status | `hub:modules:*` |
| `/api/v1/flags` | flags | list/upsert/delete | `hub:flags:*` |
| `/api/v1/bootstrap-tokens` | bootstrap tokens | create (secret once)/list/revoke | `hub:bootstrap:*` |
| `/api/v1/agent` | enroll, token, sync, status, modules/{id}/binary | — | bootstrap / refresh / `hub:agent:sync`, `hub:agent:report` |
| `/healthz`, `/readyz` | probes | — | none |

Envelope: every JSON response (success and error) is `{status, data, meta:{version, timestamp, trace_id}}` per `backend.md`; `application/wasm` bodies, 302 and 304 are unwrapped. Errors: RFC 9457 problem object inside `data`, with int `code` and `trace_id`. Pagination: `limit` (≤200) + opaque `cursor` → `next_cursor`.

## Agent Protocol

See `docs/hub-protocol.md`: enroll → poll `/api/v1/agent/sync` with ETag → verify modules locally → apply clamp → report status; 410 = revoked; offline cache until `max_stale_s`.

## CLI Tree (pdcli, extends `penguin-cli-core`)

```
pdcli hub
├── login | logout | whoami              # OIDC device flow, keychain
├── group   list|create|get|edit|delete|members set|modules set
├── agent   list|get|revoke|override set|override clear
├── module  list|upload <wasm> --sig <minisig>|get|yank
├── flag    list|set <key> --enabled=<bool> [--group]|delete
└── bootstrap create [--group ..] [--ttl]|list|revoke
```

Output: table default, `--json`. Exit codes non-zero on any API error.

## Open Questions

1. **mTLS termination / SPIRE availability** — terminate at ingress (forward XFCC/SVID header) vs in-pod hypercorn TLS; is SPIRE live in alpha? Until known, JWT path is the default
2. **Key rotation** — agents need multiple trusted pubkeys (current + next) and a revocation story; hub may store pubkeys for upload-time verification only
3. **`max_stale` expiry** — default value and what degrades past it (proposal in protocol doc)
4. **GitHubFetcher vs HubFetcher** — recommend a sibling `HubFetcher` implementing the same trait; keeps GitHub path untouched and isolates auth/ETag logic
5. ~~Response envelope / path prefix~~ — **closed**: follow `backend.md` — admin `/api/v1/...`, agent `/api/v1/agent/...`, `{status,data,meta}` envelope on all JSON responses; binary and 304 unwrapped
